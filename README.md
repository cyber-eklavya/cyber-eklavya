---

## 🎯 What we're building

**Anviksh AIM (AI-Assisted Marking)** is an evaluation platform for schools, Nursery to Class 12.

- 📄 Scans handwritten answer sheets and splits them into questions
- 🧠 Grades against the teacher's rubric, **CBSE-style OSM**, part by part
- ✅ Keeps the teacher in control: every mark can be reviewed, edited or overridden
- 📊 Produces student assessment reports and school-level analytics
- ⏱️ Returns evaluated results within **15 working days**
- 🏫 Multi-school, multi-role: platform admin, school admin, teachers, read-only school login, and student results view
